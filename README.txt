TECNOMARKET_PRO_PERU - Instrucciones de instalación
1) Copia la carpeta TECNOMARKET_PRO_PERU_FINAL dentro de C:\xampp\htdocs\
2) Inicia Apache y MySQL desde XAMPP
3) Abre en el navegador: http://localhost/TECNOMARKET_PRO_PERU_FINAL/
4) El sistema crea la base de datos y tablas automáticamente la primera vez que cargues la web.
5) Usuario admin por defecto: admin@tecnomarket.pe  |  Clave: admin123
6) Para correos reales instala PHPMailer y configura SMTP en includes/email.php
7) Si deseas cambiar el logo o imágenes sustituye los archivos en imagenes/productos/
